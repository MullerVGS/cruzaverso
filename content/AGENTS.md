# Catálogo

Conteúdo PT-BR local, versionado e empacotado. O runtime não consulta internet nem IA.

- `biomes/`: seis lotes editoriais; siga o `AGENTS.md` local.
- `datasetVersion` descreve a edição; `contentFingerprint` identifica o conteúdo real.
- Mudança jogável precisa atualizar identidade sem alterar edição diária publicada.
- Rode `npm run validate:content`, `npm run audit:editorial` e testes de catálogo.
- Fontes servem à checagem. Não copie pistas ou definições.
